# Terra Mystica Fire & Ice — Final Scoring Tiles

BGA game option: "Fire and Ice - Final Scoring tiles" (Off / On / Random).

During setup, 1 Final Scoring tile is drawn and placed face-up. It is scored **after** the Area scoring at the end of the game.

## General Rules

Each Final Scoring tile follows Area scoring rules:
- Only structures within the same cluster of **directly or indirectly adjacent** (connected) structures count
- 18/12/6 VP for 1st/2nd/3rd best player
- Ties: add VP for tied ranks, divide evenly, round down

## The 4 Final Scoring Tiles

### Greatest Distance

Each player determines the distance between the two of their **connected** structures that are the farthest apart. Count the number of spaces between those two structures (counting the space of one of them). If there are multiple paths, use the shortest one.

### Stronghold and Sanctuary

Each player determines the distance between their Stronghold and Sanctuary (they must be connected). Count spaces between them (counting one of them). If multiple paths, use the shortest. If you did not build both structures, you get 0 VP.

### Outposts

Each player counts the number of their structures built on **border spaces** of the map. These structures must be connected.

### Settlements

Each player counts the number of their **Settlements**. A Settlement is a cluster of **directly adjacent** structures of one color. Single isolated structures also count as Settlements. Scored Settlements must be connected.

Note: All structures in a Mermaid Town crossing a river are considered part of the same Settlement.
